## ⚠️ Problem Statement

Modern students and working professionals encounter severe bottlenecks during career advancement:

1. **Fragmented Career Information**: Career data, salary benchmarks, and skill requirements are scattered across disparate websites.
2. **Generic & Outdated Resumes**: Job seekers struggle to build ATS-compliant resumes with quantified impact statements.
3. **Lack of Interview Practice**: Candidates lack interactive platforms to simulate realistic technical and behavioral interviews with immediate feedback.
4. **Disorganized Learning Paths**: Learners waste time sifting through thousands of unverified online courses and eBooks without clear roadmaps.

---

## 💡 The Futuro AI Solution

**Futuro AI** unifies career discovery, resume engineering, interview preparation, and skill learning into a single intelligent platform:

- **AI-Powered Career Matching**: Analyzes user background, interests, and strengths to calculate compatibility scores across 50+ modern professions.
- **Instant A4 ATS Resume Engineering**: Built-in resume builder with AI bullet enhancers and 1-click A4 PDF export.
- **Conversational Copilot**: 24/7 intelligent career strategist powered by Google Gemini API.
- **Interactive Interview Coaching**: STAR-method AI interview scoring for behavioral and technical drills.
- **Curated Learning Hub**: Aggregated catalog of courses, verified certifications, eBooks, and NIRF-ranked colleges.

## 🤖 AI Architecture

Futuro AI leverages Google Gemini API for context-aware intelligence:

```
[ User Prompt / Inputs ] ──> [ Frontend Client ]
                                   │
                                   ▼
                       [ Express Backend API ]
                                   │
                                   ▼
                 [ Prompt Engineering & Context Layer ]
                                   │
                                   ▼
            [ Google Gemini API (gemini-1.5-flash) ]
                                   │
                                   ▼
          [ JSON Parsing / Conversational Markdown Formatting ]
                                   │
                                   ▼
                        [ Client Rendered UI ]
```

- **Primary Model**: `gemini-1.5-flash` via Google Generative Language API `v1beta`.
- **Secondary Fallback**: `gemini-2.0-flash` & `gemini-1.5-pro`.
- **Graceful Client Fallback**: High-intelligence intent engine for instant response delivery.

## 🔒 Authentication & Security

- **Google OAuth 2.0**: Direct Firebase Web SDK (`GoogleAuthProvider`) with explicit prompt selection (`prompt: 'select_account consent'`).
- **Session Tokens**: Signed JSON Web Tokens (JWT) transmitted via HTTP Authorization headers.
- **API Security**: `helmet` header protection, CORS origin restriction, and `express-rate-limit` middleware limiting IP requests.

---

## 🗄️ Database Architecture

MongoDB Atlas Cloud Database schemas managed via Mongoose:

1. **User Schema**: Profile info, role, current skills, target career, saved bookmarks.
2. **Career Schema**: Titles, salary ranges, growth rates, required skills, recommended paths.
3. **ChatMessage Schema**: User ID, role (`user` | `assistant`), message content, timestamp.
4. **Resume Schema**: User ID, personal info, summary, work experience, education, skills, design theme.

## 🔌 API Overview

| Method | Endpoint | Description |
| :--- | :--- | :--- |

## 🚀 Local Development Setup

### 1. Prerequisites
- Node.js >= 20.x
- Git

### 2. Clone Repository
```bash
git clone https://github.com/heetchheda06/Futuro-AI.git
cd Futuro-AI
```

### 3. Backend Setup
```bash
cd backend
npm install
npm run dev
```
*Backend will run locally on `http://localhost:5000`.*

### 4. Frontend Setup
```bash
cd ../frontend
npm install
npm run dev
```
*Frontend will run locally on `http://localhost:3000`.*
