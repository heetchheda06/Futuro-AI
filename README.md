## 📌 Overview

**Futuro AI** is an AI-driven career intelligence and learning platform designed to bring the major stages of career preparation into one connected ecosystem.

Instead of using separate platforms for career research, skill analysis, learning discovery, resume creation, and interview practice, Futuro AI connects these workflows into a single personalized journey.


# 🎯 Problem Statement

Students and early-career professionals often face several connected problems:

* Career information is scattered across multiple platforms.
* It is difficult to understand which skills are required for a target career.
* Generic resumes often fail to communicate measurable impact.
* Interview preparation is disconnected from individual career goals.
* Thousands of courses and learning resources make it difficult to choose a structured learning path.
* Career, college, skill, and learning decisions are often made without one unified view of the user's goals.

### The Core Problem

> **Career preparation is fragmented. Futuro AI brings the major parts of that journey into one intelligent ecosystem.**

---

# 💡 Our Solution

Futuro AI combines career intelligence, AI assistance, skill analytics, learning discovery, resume engineering, interview preparation, and productivity tools.

### The platform helps users:

1. 🎯 **Discover** suitable career paths
2. 🔍 **Compare** career opportunities
3. 📊 **Assess** current skills and academic performance
4. 🧩 **Identify** skill gaps
5. 🗺️ **Generate** personalized learning roadmaps
6. 📚 **Discover** courses, certifications, eBooks, and colleges
7. 📄 **Build** ATS-friendly resumes
8. 🎙️ **Practice** HR, technical, and behavioral interviews
9. 🤖 **Improve** through AI-generated feedback
10. 🚀 **Track** career preparation and productivity

# 🔐 Authentication & Security

Futuro AI implements multiple layers of application security.

### Authentication

* Firebase Authentication
* Google OAuth 2.0
* Google account selection flow
* JWT-based backend session handling

### API Security

* Helmet security headers
* CORS configuration
* Express rate limiting
* Authorization headers
* Protected backend routes

### Security Principle

> API credentials and backend secrets must remain server-side and should never be committed to the repository.

MongoDB Atlas is used as the cloud database with Mongoose for schema management.

# 🔌 API Overview

| Method | Endpoint                        | Purpose                                        |
| ------ | ------------------------------- | ---------------------------------------------- |
| `POST` | `/api/auth/google`              | Authenticate Google account and create session |
| `GET`  | `/api/careers`                  | Retrieve career information                    |
| `POST` | `/api/resumes/generate-summary` | Generate AI resume summary                     |
| `POST` | `/api/resumes/enhance-bullet`   | Improve resume bullet                          |
| `GET`  | `/api/chats`                    | Retrieve chat history                          |
| `POST` | `/api/chats`                    | Send message to AI Copilot                     |

> The endpoints above represent the documented core API. Additional endpoints may exist in the backend implementation.

# 🚀 Local Development

## Prerequisites

* Node.js `>= 20.x`
* npm
* Git
* MongoDB Atlas account
* Firebase project
* Google Gemini API access

## 1. Clone Repository

```bash
git clone https://github.com/heetchheda06/Futuro-AI.git
cd Futuro-AI
```

## 2. Backend Setup

```bash
cd backend
npm install
npm run dev
```

Backend:

```text
http://localhost:5000
```

## 3. Frontend Setup

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

Frontend:

```text
http://localhost:3000
```

# 🔑 Environment Variables

Create the required environment files locally.

## Backend — `backend/.env`

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
GOOGLE_CLIENT_ID=your_google_client_id
GEMINI_API_KEY=your_gemini_api_key
```

## Frontend — `frontend/.env.local`

```env
NEXT_PUBLIC_API_URL=http://localhost:5000/api
NEXT_PUBLIC_FIREBASE_API_KEY=your_firebase_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_firebase_auth_domain
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_firebase_project_id
NEXT_PUBLIC_GOOGLE_CLIENT_ID=your_google_client_id
```

### ⚠️ Never Commit Secrets

```text
.env
.env.local
service-account.json
private API keys
JWT secrets
database credentials
```

Use environment variables for production deployments.
